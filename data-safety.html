데이터 안전 안내

이 페이지는 급식레벨업이 앱 기능 제공을 위해 사용하는 데이터와 공유 원칙을 설명합니다. 플랫폼에 따라 제공 기능과 저장 범위가 다릅니다.

기본 원칙

  • 회원가입, 이메일, 전화번호, 실명 입력 없이 사용할 수 있습니다.
  • 광고, 인앱결제, 광고 추적 SDK를 사용하지 않습니다.
  • 식사 기록과 캐릭터 성장 정보는 기본적으로 기기 내부에 저장됩니다.
  • 실제 급식을 불러오지 못한 경우 샘플 식단으로 자동 대체하지 않습니다.

앱인토스 Lite v2에서 사용하는 정보

  • 별명, 선택 학교, 선택 알레르기 코드
  • 메뉴별 최종 식사 기록과 누적 XP
  • 마지막 정상 급식 캐시와 저장 시각

이 정보는 토스 앱의 기기 저장소에 보관됩니다. 앱인토스 Lite v2는 사진, 부모 연결, 공유 카드, 알림, 분석 및 추적 기능을 사용하지 않습니다.

iOS·Android 앱 기능에 사용하는 정보

  • 별명, 선택 학교, 선택 알레르기 코드
  • 먹은 정도, 어려운 이유, 한 입 도전 기록
  • 캐릭터 레벨, 뱃지, XP 기록
  • 부모 연결용 초대 코드와 아이 구분 ID

iOS·Android 앱의 부모 공유

이 기능은 앱인토스 Lite v2에는 없습니다. iOS·Android 앱의 부모 공유는 사용자가 기록 공유를 선택한 경우에만 동작합니다. 공유 대상은 먹은 정도, 한 입 도전 기록, 알레르기 주의로 제한됩니다.

NEIS 공공데이터

선택한 학교 코드와 조회 날짜는 NEIS 학교기본정보 API와 급식식단정보 API 요청에 사용될 수 있습니다. 앱은 실제 학교 오류 상태에서 샘플 급식을 자동 대체하지 않습니다.

알레르기 안내

알레르기 정보는 교육용 참고 정보입니다. 급식레벨업은 알레르기 안전을 보장하지 않으며, 학교 안내와 보호자 판단이 항상 우선입니다.

iOS·Android 앱의 공유 카드

이 기능은 앱인토스 Lite v2에는 없습니다. iOS와 Android의 SNS 공유 카드는 운영체제 기본 공유 시트를 사용합니다. 공유 카드에는 학교 상세 정보, 아이 이름, 개인 알레르기 정보, 부모 리포트 전체, 식사량 상세기록을 넣지 않습니다.
