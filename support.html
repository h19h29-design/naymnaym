급식레벨업으로 돌아가기

지원 안내

학교 검색, 급식 조회 또는 식사 기록이 원활하지 않을 때 아래 내용을 순서대로 확인해 주세요. 보호자 연결과 사진은 iOS·Android 앱에서만 제공하며 앱인토스 Lite v2에는 없습니다.

앱인토스 Lite v2에서 이용할 수 있는 기능

오늘 급식, 월요일부터 일요일까지의 주간 급식, 알레르기 주의, 메뉴별 최종 기록과 12단계 XP 성장을 제공합니다. 로그인, 사진, 보호자 연결, 월간 달력은 제공하지 않습니다.

학교가 검색되지 않아요

학교 이름을 두 글자 이상 입력하고 잠시 기다려 주세요. 같은 이름의 학교가 여러 곳이라면 지역과 주소를 함께 확인하세요. 계속 검색되지 않으면 Wi-Fi 또는 모바일 데이터 연결을 확인한 뒤 다시 시도해 주세요.

학교 검색에 실패했다는 안내가 나와요

일시적인 네트워크 또는 NEIS 공공데이터 서비스 문제일 수 있습니다. 인터넷 연결을 확인하고 잠시 후 다시 검색해 주세요. 사용자가 별도의 API 키를 입력할 필요는 없습니다.

급식 정보가 없다고 나와요

방학, 재량휴업일, 급식 미운영일이거나 NEIS에 아직 식단이 등록되지 않았을 수 있습니다. 급식레벨업은 불러오지 못한 실제 급식을 샘플 식단으로 바꾸어 표시하지 않습니다.

등록한 학교를 바꾸고 싶어요

앱의 설정 또는 프로필 화면에서 학교 다시 선택을 누른 뒤 새 학교를 검색해 등록해 주세요. 변경 후에는 새로 등록한 학교의 급식이 표시됩니다.

알레르기 메뉴는 먹어도 되나요?

앱은 알레르기 안전을 보장하지 않습니다. 선택한 알레르기와 관련된 메뉴는 한 입 도전보다 보호자와 학교 안내 확인이 먼저입니다.

AI 식단 해설은 어떻게 사용하나요?

iOS·Android 앱의 오늘 화면 또는 급식표 오늘 날짜에서 “오늘 식단 AI 해설”을 열고 전송 항목을 확인한 뒤 동의해 주세요. 새 해설은 하루 한 번 만들 수 있고 생성된 결과는 기기에 저장됩니다. AI 해설은 참고용이며 영양사·의료 상담을 대신하지 않습니다. 앱인토스 Lite v2에는 이 기능이 없습니다.

AI 해설이 만들어지지 않아요

오늘 급식이 없거나, 알레르기 주의 메뉴와 영양정보가 없는 메뉴만 있거나, 하루 사용을 이미 완료한 경우에는 새 해설을 만들지 않습니다. 네트워크 오류라면 자동 재요청하지 않으므로 연결을 확인한 뒤 안내에 따라 다시 시도해 주세요.

기록을 잘못 저장했어요

앱인토스 Lite v2에서는 같은 날짜와 메뉴의 기록 버튼을 다시 누르면 최종 선택으로 교체됩니다. iOS·Android 앱에서는 같은 급식의 기록 화면을 다시 열어 먹은 정도와 어려웠던 이유를 수정할 수 있습니다. 전체 기록을 지우려면 설정의 데이터 관리에서 삭제할 수 있으며, 삭제한 기록은 복구할 수 없습니다.

iOS·Android 앱에서 부모 연결이 안 돼요

이 기능은 앱인토스 Lite v2에는 없습니다. iOS·Android 앱에서는 아이 기기에서 만든 보호자 연결 초대 코드를 부모 모드의 아이 연결 화면에 정확히 입력해 주세요. 코드는 영문과 숫자를 구분하며, 만료되었거나 이미 사용된 코드는 다시 발급해야 할 수 있습니다.

문의 전 확인

  • 학교 이름을 두 글자 이상 정확히 입력했는지 확인
  • Wi-Fi 또는 모바일 데이터 연결 확인
  • 앱을 완전히 종료한 뒤 다시 실행
  • Play 스토어, App Store 또는 토스 앱에서 최신 버전 확인
  • 데이터 삭제 전 되돌릴 수 없다는 점 확인

문의 채널

앱 오류나 급식 조회 문제는 급식레벨업 GitHub Issues에 남길 수 있습니다. 공개 게시판이므로 아이 이름, 학교 상세 정보, 알레르기 개인 정보, 사진, 연락처는 올리지 마세요.
