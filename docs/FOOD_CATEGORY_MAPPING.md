# 급식 메뉴 분류와 아이콘 매핑

메뉴명은 괄호 속 알레르기 번호와 불필요한 공백을 정리한 뒤 `MealVisualResolver`와 영양 규칙 엔진에서 분류한다. 개별 메뉴에는 정량 영양값을 만들지 않고 대표 식품군·대표 영양소·추정 신뢰도만 표시한다.

| 대표 메뉴 예시 | 분류 | 아이콘 키 | 대표 안내 |
| --- | --- | --- | --- |
| 밥, 현미밥, 볶음밥, 비빔밥 | grain | `food.grain` | 탄수화물·에너지 |
| 국, 탕, 찌개, 미역국 | soup | `food.soup` | 주재료가 명확할 때만 해당 영양소 |
| 불고기, 제육볶음, 갈비 | meat | `food.meat` | 단백질·철분·아연 |
| 고등어구이, 생선조림 | fish | `food.fish` | 단백질·일부 미네랄 |
| 달걀찜, 계란말이 | egg | `food.egg` | 단백질·비타민 A |
| 두부조림, 콩 요리 | bean | `food.bean` | 단백질·철분·칼슘 |
| 나물, 샐러드, 채소무침 | vegetable | `food.vegetable` | 식이섬유·비타민·엽산 |
| 배추김치, 깍두기 | kimchi | `food.kimchi` | 식이섬유·비타민 일반 안내 |
| 사과, 귤, 과일 | fruit | `food.fruit` | 비타민 C·식이섬유 |
| 우유, 요구르트, 치즈 | dairy | `food.dairy` | 칼슘·단백질 |
| 면, 국수, 우동 | noodle | `food.noodle` | 탄수화물·에너지 |
| 빵, 샌드위치 | bread | `food.bread` | 탄수화물·에너지 |
| 분류 불가 메뉴 | other | `food.other` | 일반 안내·낮은 신뢰도 |

## 안전 규칙

- 같은 급식에서 대체 메뉴를 제안할 때 자기 자신과 아이의 알레르기 위험 메뉴는 제외한다.
- 알레르기 메뉴는 먹기 권유나 영양 손실 문구 대신 `안전하게 피했어요`를 우선한다.
- `오늘은 안 먹어요`와 적게 먹은 상태는 “대표 영양소를 덜 섭취할 수 있어요”처럼 교육적 가능성으로만 설명한다.
- 정확한 g·mg·kcal 수치는 NEIS가 제공한 전체 급식 합계에서만 출처와 함께 표시한다.
- 분류 실패나 아이콘 누락은 빈 공간이나 크래시 대신 `food.other` 시스템 아이콘으로 대체한다.

현재 번들에는 출처가 불명확한 외부 PNG를 추가하지 않았다. 사용 중인 시스템 아이콘과 향후 원화 교체 지점은 [MEAL_ICON_ASSET_MANIFEST.md](MEAL_ICON_ASSET_MANIFEST.md)에 기록한다.
