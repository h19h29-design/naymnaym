# 급식레벨업 지원 안내

## 지원 범위
- 학교 검색이 되지 않는 경우
- 급식 정보가 표시되지 않는 경우
- 식사 기록을 수정하거나 삭제하는 경우
- 부모 연결 초대 코드 안내
- 데이터 삭제 방법

## 자주 묻는 질문

### 학교가 검색되지 않아요.
학교 이름을 두 글자 이상 입력하고 잠시 기다려 주세요. 같은 이름의 학교가 여러 곳이라면 지역과 주소를 함께 확인하세요. 계속 검색되지 않으면 Wi-Fi 또는 모바일 데이터 연결을 확인한 뒤 다시 시도해 주세요.

### 학교 검색에 실패했다는 안내가 나와요.
일시적인 네트워크 또는 NEIS 공공데이터 서비스 문제일 수 있습니다. 인터넷 연결을 확인하고 잠시 후 다시 검색해 주세요. 사용자가 별도의 API 키를 입력할 필요는 없습니다.

### 급식 정보가 없다고 나와요.
방학, 재량휴업일, 급식 미운영일이거나 NEIS에 아직 식단이 등록되지 않았을 수 있습니다. 실제 학교 선택 상태에서는 샘플 급식으로 대체하지 않습니다.

### 등록한 학교를 바꾸고 싶어요.
앱의 설정 또는 프로필 화면에서 학교 다시 선택을 누른 뒤 새 학교를 검색해 등록해 주세요.

### 알레르기 메뉴는 먹어도 되나요?
앱은 알레르기 안전을 보장하지 않습니다. 선택한 알레르기와 관련된 메뉴는 한 입 도전보다 보호자와 학교 안내 확인이 먼저입니다.

### 기록을 잘못 저장했어요.
같은 급식의 기록 화면을 다시 열어 먹은 정도와 어려웠던 이유를 수정해 주세요. 전체 기록을 지우려면 설정의 데이터 관리에서 삭제할 수 있으며, 삭제한 기록은 복구할 수 없습니다.

### 회원가입이 필요한가요?
필요 없습니다. 별명과 학교만 선택하면 사용할 수 있습니다.

## 문의 전 확인할 항목
- 학교 이름을 두 글자 이상 정확히 입력했는지 확인
- Wi-Fi 또는 모바일 데이터 연결 확인
- 앱을 완전히 종료한 뒤 다시 실행
- Play 스토어 또는 App Store에서 최신 버전 확인
- 데이터 삭제 전 되돌릴 수 없다는 점 확인
