# 급식레벨업 앱인토스 급식 없음 화면 개선 설계

## 목표

오늘 급식이 등록되지 않은 날에도 화면이 비어 보이지 않게 한다. 사용자가 지금까지 성장시킨 캐릭터를 계속 확인하고, 가장 가까운 다음 급식과 주간 급식표로 자연스럽게 이동할 수 있어야 한다.

별도 유료 서비스나 서버 저장소는 추가하지 않는다. 기존 Apps-in-Toss 클라이언트와 Supabase 무료 NEIS 중계 함수만 사용한다.

## 현재 문제

- `NO_DATA` 응답은 `noMeal` 한 종류로 처리된다.
- 오늘 화면은 “오늘은 등록된 급식이 없어요”라는 문장과 비활성 기록 버튼만 보여 준다.
- 사용자가 다음 급식을 확인하려면 직접 급식표 탭으로 이동해 날짜를 찾아야 한다.
- 급식이 없는 날에는 성장 캐릭터와 앱의 정체성이 충분히 드러나지 않는다.
- 주말·공휴일·학교 미등록처럼 NEIS가 구분하지 않는 사유를 앱이 임의로 단정해서는 안 된다.

## 채택한 접근

캐릭터 중심의 쉬는 날 화면을 제공한다.

1. 현재 XP로 계산한 성장 단계 캐릭터를 빈 상태의 중심에 유지한다.
2. 오늘 급식이 없으면 향후 7일 안의 평일을 가까운 날짜부터 조회한다.
3. 첫 번째 실제 급식을 찾으면 날짜와 메뉴를 미리 보여 준다.
4. 사용자는 `주간 급식표 보기`로 전체 급식표에 이동하거나 `다시 확인`으로 오늘 급식을 재조회할 수 있다.
5. 향후 7일 안에 급식이 없으면 학교 설정과 주간 급식표로 이동할 수 있게 한다.

단순 문구·버튼만 추가하는 접근은 브랜드 경험이 약해 채택하지 않는다. 급식 없는 날 별도 미션이나 XP를 지급하는 접근은 기존 성장 규칙을 복잡하게 하고 급식 기록과 무관한 보상을 만들기 때문에 채택하지 않는다.

## 화면 설계

### 캐릭터 영역

- 현재 `progress.totalXp`를 `levelFor`에 전달해 성장 단계를 계산한다.
- 해당 단계의 `/growth/level-{n}.png`를 표시한다.
- 캐릭터 메시지는 `오늘은 급식이 없는 날이에요. 다람쥐도 잠깐 쉬어가요!`로 표시한다.
- 현재 레벨과 누적 XP는 기존 성장 요약에 그대로 표시한다.

### 오늘 급식 없음 카드

- 제목: `오늘은 급식이 없는 날이에요`
- 설명: `학교에 등록된 다음 급식을 찾아봤어요.`
- 오늘 급식 기록 버튼은 표시하지 않는다. 비활성 버튼으로 막힌 행동을 보여 주지 않는다.
- `다시 확인` 버튼은 기존 `retry`를 호출한다.

### 다음 급식 미리보기

다음 급식을 찾은 경우 다음 내용을 표시한다.

- `다음 급식` 상태 라벨
- `8월 10일 월요일` 형식의 날짜
- 칼로리 정보가 있으면 함께 표시
- 전체 메뉴 목록과 알레르기 주의 표시
- `주간 급식표 보기` 버튼

다음 급식을 찾지 못한 경우 다음 내용을 표시한다.

- `향후 7일 안에 등록된 급식을 찾지 못했어요.`
- `주간 급식표 보기` 버튼
- `학교 설정 확인` 버튼

### 탐색 연결

- 주간 급식표 버튼은 `/meals?mode=weekly`로 이동한다.
- 학교 설정 버튼은 `/onboarding?mode=edit&next=%2Ftoday`로 이동해 학교를 바로 다시 선택하게 한다.
- 급식표 화면은 쿼리 문자열의 `mode=weekly`를 읽어 주간 보기로 시작한다.

## 데이터 흐름

1. 기존 `loadTodayMeal`이 오늘 날짜에 `NO_DATA`를 받으면 `noMeal`을 반환한다.
2. 오늘 화면은 별도 `useNextMeal` 훅을 활성화한다.
3. 훅은 서울 날짜 기준 다음 날부터 7일 동안 토요일과 일요일을 제외하고 가까운 날짜부터 순차 조회한다.
4. 실제 급식을 찾으면 즉시 탐색을 멈추고 반환한다.
5. `NO_DATA`는 다음 날짜 조회를 계속한다.
6. 네트워크·설정·요청 제한 오류는 다음 급식 영역의 오류 상태로 반환한다.
7. 조회 오류가 난 날짜에 정확한 날짜의 기기 캐시가 있으면 저장된 다음 급식으로 표시한다.
8. 성공한 다음 급식은 기존 기기 캐시에 저장한다. 저장 실패는 결과 표시를 막지 않는다.

최대 조회 수는 향후 7일에 포함된 평일 수인 5회다. 오늘 급식이 존재하는 정상 경로에서는 추가 요청이 발생하지 않는다.

## 상태와 오류 처리

- 오늘 급식 조회 오류는 기존 `AppErrorState`와 재시도를 유지한다.
- 오늘 급식이 없고 다음 급식 조회 중이면 캐릭터와 오늘 없음 안내를 먼저 보여 주고 미리보기 영역만 로딩 상태로 표시한다.
- 다음 급식 조회 오류를 오늘 급식 없음으로 숨기지 않는다.
- 다음 급식 조회 오류에는 `다음 급식을 불러오지 못했어요`와 재시도 버튼을 표시한다.
- 주말이라고 계산할 수 있어도 NEIS가 제공하지 않는 휴일 사유는 단정하지 않는다.
- 체험 모드는 기존 체험 급식을 사용하며 다음 급식 자동 조회를 하지 않는다.
- 캐시 데이터와 실제 데이터 라벨은 기존 구분을 유지한다.

## 컴포넌트 경계

### `useNextMeal`

- 역할: 다음 조회 후보 날짜 생성, NEIS 순차 조회, 캐시 저장, 취소와 재시도 처리
- 입력: 학교 프로필, NEIS 클라이언트, 저장소, 활성 여부
- 출력: `idle`, `loading`, `ready`, `notFound`, `error` 상태

### `NoMealState`

- 역할: 오늘 급식 없음 안내, 현재 캐릭터, 다음 급식 상태와 이동 버튼 표시
- 입력: 현재 레벨, 다음 급식 결과, 알레르기 번호, 재시도 및 이동 콜백
- 네트워크와 저장소를 직접 호출하지 않는다.
- `TodayPage`는 `noMeal`일 때 기존 캐릭터 영역, 단문 급식 카드와 비활성 기록 버튼 대신 이 컴포넌트를 한 번만 렌더링한다.

### `MealSchedulePage`

- 역할: `mode` 쿼리 문자열을 초기 보기 상태에 반영
- 기존 일간·주간·월간 조회와 화면 구조는 유지한다.

## 테스트

### 단위 테스트

- 다음 7일에서 주말을 제외한 후보 날짜를 올바른 서울 날짜로 생성한다.
- 첫 급식을 찾으면 후속 요청을 하지 않는다.
- `NO_DATA` 후 다음 날짜의 급식을 반환한다.
- 5개 평일 모두 `NO_DATA`이면 `notFound`를 반환한다.
- 조회 오류와 `NO_DATA`를 구분한다.
- 정확한 날짜의 캐시만 다음 급식으로 사용한다.
- 성공한 다음 급식의 캐시 쓰기 실패가 결과를 바꾸지 않는다.

### 화면 테스트

- 오늘 급식 없음 상태에서 현재 레벨 캐릭터와 누적 XP가 보인다.
- 다음 급식의 날짜, 메뉴와 알레르기 주의가 보인다.
- 오늘 급식 기록 비활성 버튼은 보이지 않는다.
- `다시 확인`이 오늘 급식 재조회를 호출한다.
- `주간 급식표 보기`가 주간 모드로 이동한다.
- 다음 급식이 없으면 학교 설정 버튼이 보인다.
- 다음 급식 조회 오류에는 오류와 재시도가 보인다.

### 회귀 검증

- 실제 오늘 급식 기록, 저장된 급식, 체험 급식, 조회 오류가 기존대로 동작한다.
- 전체 Vitest, TypeScript 검사, 웹 빌드, Apps-in-Toss 릴리스 검증을 통과한다.
- 새 `.ait` 번들을 토스 콘솔에 등록하고 QR 테스트 버전을 생성한다.

## 비용과 운영

- Supabase Database, Auth, Storage 또는 새로운 서버를 추가하지 않는다.
- 오늘 급식이 없는 경우에만 최대 5회의 기존 Edge Function 호출이 추가된다.
- 무료 요금제 한도를 넘어 자동 결제되는 설정을 사용하지 않는다.
- 사용자 데이터는 기존처럼 토스 기기 저장소에만 저장한다.
