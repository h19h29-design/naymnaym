# 냠냠레벨업 첫 화면 로고 모션 디자인

## 목표

첫 화면의 `냠냠레벨업` 로고에 한 번만 재생되는 브랜드 모션을 추가한다. 캐릭터의 지속적인 호흡 모션과 경쟁하지 않도록 로고는 등장 후 완전히 정지한다.

## 승인된 시퀀스

로고 원본은 357×86 투명 PNG이며, 두 번째 `냠`은 x=138에서 끝나고 `레`는 x=146에서 시작한다. x=139–145의 완전 투명한 구간 중앙인 정규화 위치 `0.40`에서 두 레이어를 분리한다.

1. `냠냠` 묶음과 왼쪽 잎 장식이 0.04초에 시작해 0.76초 동안 등장한다.
2. `레벨업` 묶음과 오른쪽 잎 장식이 0.34초에 시작해 0.76초 동안 등장한다.
3. 각 묶음은 10px 아래, 0.988배, 투명 상태에서 시작해 원래 위치와 크기로 부드럽게 안착한다.
4. 두 묶음이 완성된 뒤 1.18초에 로고 전체를 마스크로 사용하는 밝은 빛이 왼쪽에서 오른쪽으로 0.82초 동안 한 번 지나간다.
5. 2.00초 이후 로고는 원래 상태로 정지하고 반복하지 않는다.

이징은 큰 반동이 없는 `cubic-bezier(0.22, 0.78, 0.36, 1)` 계열을 사용한다. 글자 묶음 사이에는 투명 여백만 존재하므로 `ㅑ`와 `ㄹ`의 획이 분리되거나 중복되어서는 안 된다.

## 플랫폼 구현

### iOS

- `LogoHeader` 안에서 동일한 로고 이미지를 두 겹으로 그린다.
- 왼쪽 레이어는 너비의 40%, 오른쪽 레이어는 나머지 60%만 마스킹한다.
- SwiftUI 비동기 작업으로 두 등장 애니메이션과 빛 애니메이션을 순서대로 실행한다.
- 화면이 사라지면 작업이 취소되고, 같은 뷰 인스턴스에서는 한 번만 재생한다.
- 로고 에셋이 없으면 기존 `RequiredAssetPlaceholder`를 그대로 사용한다.

### Android

- 같은 로고 drawable을 사용하는 두 `ImageView`를 `FrameLayout`에 겹친다.
- 실제 drawable이 `FIT_CENTER`로 표시되는 콘텐츠 영역을 계산하고 그 영역의 40% 지점에서 `clipBounds`를 나눈다.
- 두 단어 묶음은 `ViewPropertyAnimator`로 순차 등장시킨다.
- 세 번째 흰색 tint 로고 레이어의 좁은 `clipBounds`를 `ValueAnimator`로 이동해 빛 효과를 만든다.
- 화면을 다시 구성할 때 이전 애니메이터가 새 화면을 건드리지 않도록 컨테이너에 연결된 애니메이터만 실행한다.

## 동작 줄이기

- iOS `accessibilityReduceMotion`이 켜져 있으면 이동, 확대·축소, 빛 효과를 끈다.
- Android 시스템 애니메이션이 비활성화되어 있으면 이동과 빛 효과를 끈다.
- 두 경우 모두 로고 전체만 0.25초 동안 페이드인한다.

## 검증

- iOS와 Android에서 분할 비율 `0.40`, 시작 시각, 지속 시간, 이동 거리, 빛 시작 시각을 단위 테스트로 고정한다.
- Android에서는 실제 표시 영역 기준 분할 좌표 계산을 단위 테스트한다.
- iOS 테스트, Android JVM 테스트, 양 플랫폼 debug 빌드를 실행한다.
- 배포, 스토어 업로드, 테스트 트랙 생성은 수행하지 않는다.
