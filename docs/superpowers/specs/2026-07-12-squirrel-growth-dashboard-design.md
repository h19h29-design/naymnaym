# 냠냠레벨업 다람쥐 성장 대시보드 디자인

## 목표

첨부된 다람쥐 캐릭터 레퍼런스를 냠냠레벨업의 새로운 시각 기준으로 적용한다. 기존 NEIS 급식, 알레르기 안전, 식사 기록, XP, 뱃지, 보호자 초대 및 공유 기능은 유지하면서 첫 실행, 홈, 캐릭터 성장 화면의 완성도와 성장 동기를 높인다.

보호자 연결 상태는 초대 코드 등록과 실제 부모 연결을 구분해 사실대로 표시한다. 아이 화면에는 부모 이름을 저장하거나 노출하지 않고 `보호자와 연결되었습니다`라고 표시한다. 부모 화면에는 이미 보유한 아이 닉네임으로 `OO와 연결되었습니다`라고 표시한다.

## 시각 방향

- 첨부 이미지의 따뜻한 크림색, 숲빛 초록, 오렌지, 청록 포인트를 사용한다.
- 기존 브로콜리 공룡과 SwiftUI 도형 캐릭터를 다람쥐 캐릭터로 교체한다.
- 캐릭터는 투명 배경 고해상도 래스터 에셋으로 제작한다. SwiftUI는 배경, 레이아웃, 카드, 상태 표시, 애니메이션만 담당한다.
- 카드 모서리는 8px 이하를 기본으로 하되 캐릭터 히어로 영역과 모달만 기존 디자인 시스템 범위에서 부드럽게 처리한다.
- 장식보다 캐릭터, 오늘 미션, 성장 진행률, 연결 상태를 우선한다.
- iPhone SE에서는 스크롤을 허용하되 핵심 캐릭터, 레벨, 오늘 미션, 급식 진입 버튼이 첫 화면 흐름에서 잘리지 않게 한다.

## 캐릭터 에셋

레퍼런스의 다람쥐를 기준으로 일관된 캐릭터 성장 에셋을 만든다.

- Lv.1 새싹
- Lv.2 꼬마 모험가
- Lv.3 한입 탐험가
- Lv.4 숲길 도전자
- Lv.5 냠냠 용사
- Lv.6 숲의 수호자
- Lv.7 레전드 냠냠러

모든 단계는 같은 얼굴, 털색, 눈 비율, 새싹 모티프를 유지하고 장비와 포즈만 성장시킨다. 에셋 리졸버는 현재 `PlayerProgress.level`과 `UserMode`를 입력받아 동일한 캐릭터를 인트로, 홈, 캐릭터 성장 화면에 제공한다. 에셋이 없을 때만 기존 캐릭터를 폴백으로 사용하며 출시 빌드에서는 모든 단계 에셋 존재 여부를 테스트한다.

## 첫 실행 인트로

현재 `IntroExperienceView`의 상태 분기와 급식 문구 정책은 유지한다.

- 상단에는 냠냠레벨업 로고와 `한 입 도전으로 캐릭터를 키워요!`를 배치한다.
- 중앙에는 현재 사용자 레벨의 다람쥐 캐릭터가 등장한다. 신규 사용자는 Lv.1을 표시한다.
- 배경은 첨부 이미지처럼 하늘빛과 따뜻한 빛, 잎사귀와 별 반짝임이 있는 비트맵 배경을 사용한다.
- 등장 애니메이션은 아래에서 올라오기, 0.92→1.04→1.0 바운스, 손 흔들기, 작은 별 파티클 순서로 2~3초 안에 끝낸다.
- 학교 미등록, 실제 급식 성공, 급식 없음, API 오류, 체험 모드 문구는 기존 상태 정책을 그대로 사용한다.
- 하단 버튼은 오늘 급식, 체험 모드, 보호자 모드 기능을 유지한다.

## 성장 중심 홈

`TodayMealView`를 별도 기능 페이지로 교체하지 않고 상단을 성장 대시보드로 재구성한다. 급식 목록과 기록 시트는 동일 화면 아래에서 계속 제공한다.

1. 프로필 헤더
   - 현재 레벨 캐릭터 얼굴, 닉네임, 레벨, 성장 상태
   - 알림 버튼과 누적 성장 포인트
2. 캐릭터 히어로
   - 현재 성장 단계 다람쥐
   - 레벨 진행률과 다음 레벨까지 남은 XP
   - 연속 기록일, 누적 한 입 도전, 현재 성장 단계
3. 오늘의 한 입 미션
   - 실제 급식 메뉴 기반 추천
   - 알레르기 위험 메뉴는 추천하지 않고 안전 확인을 우선
   - 오늘 기록 진행 수와 XP 예상치
4. 빠른 이동
   - 성장 리포트
   - 보상/뱃지
   - 오늘 급식 목록으로 이동
5. 기존 급식 기능
   - 실제 NEIS 상태 배너
   - 영양 요약과 메뉴별 한 입 도전/먹은 정도/잘 먹어요
   - 실제 학교 실패 시 샘플 표시 금지, 체험 모드만 샘플 표시

## 캐릭터 키우기

기존 `ProgressAndBadgesView`를 첨부 이미지의 캐릭터 성장 화면 구조로 재구성한다.

- 상단: 현재 레벨, 총 XP, 다음 단계까지 진행률
- 성장 단계: Lv.1~7 캐릭터 경로, 현재 단계 강조, 미래 단계 잠금
- 탭: 진화, 의상, 뱃지, 스토리. 이번 범위에서 진화와 뱃지는 실제 데이터로 동작하고 의상/스토리는 잠금 또는 준비 상태로 표시한다.
- 현재 캐릭터 큰 이미지와 다음 진화까지 남은 XP
- 다음 진화 보상 미리보기
- 실제 보유 뱃지와 잠긴 뱃지
- XP 4종 데이터는 유지하되 기본 화면에서는 총 성장 XP와 핵심 진행률을 우선하고 세부 내역에서 기록/도전/균형/안전 XP를 보여준다.

## 보호자 연결 상태

### 서버 계약

`connectInvite` 성공 시 `nyam_parent_links.connected_at`을 최초 연결 시각으로 기록한다. 부모 이름이나 계정 정보는 저장하지 않는다.

아이 기기는 `childLinkId + inviteSecret`으로 연결 상태를 조회하는 별도 서버 액션을 사용한다. 초대 코드만 아는 제3자가 연결 상태를 조회하지 못하도록 한다.

### 아이 화면

- 초대 코드 없음: `아직 보호자와 연결되지 않았어요`
- 서버 등록 전/실패: `초대 링크를 준비하지 못했어요`
- 초대 코드 등록, 부모 미연결: `초대 링크가 준비됐어요`
- 부모 연결 완료: `보호자와 연결되었습니다`
- 최근 동기화 실패: `연결은 유지 중이며 최근 기록을 보내지 못했어요`

연결 완료 후 기존의 큰 초대 안내 카드와 반복 메시지는 숨긴다. 홈 헤더에는 작은 상태 행만 표시하고, 누르면 연결 상세 화면으로 이동한다.

### 부모 화면

- 연결된 아이가 없으면 `아직 연결된 아이가 없어요`
- 연결 완료 직후 `OO와 연결되었습니다`
- 이후에는 `OO 연결됨 · 최근 동기화 HH:mm` 형태의 상태를 카드에 표시한다.
- 오류 메시지는 성공 메시지와 동시에 남기지 않고, 해결 후 자동으로 제거한다.

## 데이터와 호환성

- `ChildLink`에 선택적 `parentConnectedAt`을 추가해 기존 로컬 저장 데이터를 깨뜨리지 않는다.
- 서버 마이그레이션은 nullable `connected_at timestamptz`만 추가한다.
- 기존 초대 코드는 유지되며 다시 발급할 필요가 없다.
- 기존 부모 연결은 다음 상태 조회에서 연결 시각이 없으면 `초대 링크 준비`로 표시한다. 부모가 다시 새로고침하거나 연결 링크를 열면 실제 연결 상태로 전환된다.
- 연결 상태 표시와 실제 공유 권한은 분리한다. 연결됨 상태여도 사용자가 선택하지 않은 데이터는 공유하지 않는다.
