# 선택형 영양 코치 구현 계획

승인된 범위: 급식·식단 전용 질문 3개(평가/먹으면/남기면), 실제 영양정보와 기존 영양소 규칙 사용, 캐릭터 반응, iOS/Android. 자유 입력·의료 판단·개인정보 전송·배포 제외.

## 설계와 경계

- 앱 → 키를 보유한 서버 → OpenCode Go `deepseek-v4.1-flash`. Go의 일반 앱 서비스 이용 허용 여부는 아직 확인되지 않았으며 공개 운영을 시작하지 않는다.
- 먼저 로컬 개발용 서버와 비활성 기본값의 클라이언트를 구현한다. 서버는 127.0.0.1에만 바인딩하고 별도 클라이언트 인증 토큰을 요구한다. Go 키와 클라이언트 토큰은 서로 다르다.
- 메뉴 이름·학교·날짜·사용자 식사 기록·등록 알레르기는 AI에 보내지 않는다. 가정적 질문 종류·대표 영양소 ID·임시 세션 UUID를 전송하고 이를 동의문에 밝힌다. 전체 선택 시에만 전체 영양 수치를 보내며 부분 선택은 `wholeMeal={}`로 처리한다. 반찬별 수치를 추정하지 않는다.
- 질문 전 AI 전송 동의, 오류 시 명확한 기본 안내, 타임아웃, 요청/응답 크기 제한, 동시 호출 제한, 실행당 호출 상한, 입력/출력 검증. 클라이언트 디버그 설정이 없으면 오프라인 안내만 한다.
- 기본 영양 안내와 AI 설명을 구별한다. AI 결과를 영구 저장하거나 XP에 반영하지 않는다. 응답 검증은 보조 방어이며 공개 배포 전 별도 아동 안전 평가가 필요하다.

## 작업

- [x] 1. 서버 입력/인증/한도/시간초과/키 누출/응답 스키마 TDD 및 로컬 서버 구현. 모의 제공자를 사용한 Node 테스트 13개 통과.
- [x] 2. iOS 도메인/클라이언트/선택형 UI와 테스트. 기존 테스트 포함 XCTest 601개 통과, 최종 Build & Run 성공.
- [x] 3. Android 도메인/클라이언트/UI와 일간·주간·월간 통합. 단위 테스트 188개, assembleDebug/lintDebug 통과. API 35 기본/1.5배 글자 계측 각각 1개 통과 후 기본 크기 복원.
- [x] 4. 서버 모의 연동·양쪽 렌더링 확인 및 독립 보안/품질 검토. 개발 프로토타입 범위 중요 미해결 사항 없음. 커밋·푸시·배포 미실행.
- [x] 5. 사용자 키 저장 확인 후 실제 Go 응답, iOS 체험 급식 AI 표시, Android 합성 메뉴 live UI(최종 1개 PASS)를 검증했다. 양쪽 앱 내부에 개발용 토큰만 설치(600), 일반 loopback 개발 서버 활성화. 일부 생성 답변은 안전/형식 검증 거절 후 기본 안내로 전환됨을 확인했다.
- [x] 6a. 답변 실패 원인 구분, 실제 출력 잘림 확인, JSON 모드/짧은 답변 유도/출력 한도 조정, 수량 없는 요청의 잘못된 수치 참조 차단. Node 16개 PASS, 수정 후 실제 질문 3개 + iOS/Android UI 각 1개 정상 응답 확인. 작은 표본이며 지속적 안정성 평가를 대체하지 않는다.
- [ ] 6b. 더 다양한 영양소·빈 정보·경계 사례의 내용 품질/거절 빈도 평가, 일반 앱 서비스 용도 지원 확인, 운영 인증·보호자 동의·외부 처리 고지·독립 아동 안전 평가. 공개 운영/배포는 계속 HOLD.

API: POST `/v1/meal-coach`, Bearer 앱 전용 개발 토큰. 요청 `{question:"overview"|"benefits"|"omission", nutrients:["fiber"|"vitamin"|"protein"|"iron"|"calcium"|"carbohydrate"], wholeMeal:{protein?:number,carbs?:number,fat?:number}, sessionId:UUID}`. 불필요한 필드 거부. 응답 `{source:"ai", summary:string, benefit:string, caution:string, tip:string}`. 오류는 비밀 없는 `{error:code}`이며 AI 실패에는 고정된 `reason` 분류 코드도 포함한다. 영양 수치 없는 메뉴는 수치를 생성하지 않는다.

검증용 구성은 디버그 앱 내부 `meal-coach-development.json` 파일로 읽는다: `{endpoint,accessToken}`. 릴리즈에서는 읽지 않는다. 운영 인증/보호자 동의/사용 약관/개인정보 고지 검토 전 공개 AI 활성화 금지.
