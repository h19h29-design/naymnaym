# 냠냠레벨업 대규모 리뉴얼 콘셉트 보관본

작성일: 2026-07-25

## 확정된 방향

- 사용자 경험: 아이 화면은 게임처럼, 부모 화면은 차분하고 신뢰감 있게 분리
- 비주얼 세계관: A안 `살아있는 숲속 모험`
- 캐릭터 모션: 3안 `통통 튀는 게임 친구`
  - 기본 대기에서는 짧고 절제해 사용
  - 식사 완료와 레벨업에서는 크게 강조
- 캐릭터 외형: 1안 `원형 유지형`
  - 현재 얼굴과 비율, 잎사귀 스카프, 새싹, 색상 정체성을 유지
  - 실루엣, 광택, 색감, 리깅 구조만 정교하게 개선

## 보관된 대안

`character-evolution-concepts.png`에는 다음 세 방향이 모두 들어 있다.

1. 원형 유지형 — 최종 선택
2. 세련된 진화형 — 향후 브랜드 리프레시 후보
3. 과감한 게임형 — 향후 이벤트·스핀오프 후보

이 이미지는 방향 확인용 AI 콘셉트이며 앱에 바로 사용하는 최종 제작 에셋은 아니다.
실제 제작 시 모든 성장 단계가 동일한 비율과 파츠 분리 규칙을 공유하도록 다시 설계한다.
