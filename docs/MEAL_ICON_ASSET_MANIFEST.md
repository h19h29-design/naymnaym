# Meal Icon Asset Manifest

manifest_version: 1
schema: meal-icon-asset-manifest-v1

Meal visuals use the semantic keys from `MealVisualIconManifest`. The app
does not add a parallel food-art catalog: every key below resolves to the
listed iOS system symbol when no explicitly available app asset is supplied.
Meal category files are not bundled by this manifest, so every path and
checksum is `N/A`. System symbols are provided by the platform and are not
redistributed by the app.
