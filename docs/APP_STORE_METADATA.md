## 설명 기준

급식레벨업은 학교 급식 정보를 바탕으로 아이가 어려워하는 반찬을 기록하고, 작은 한 입 도전을 캐릭터 성장으로 연결하는 무료 iPhone 앱입니다.

회원가입 없이 별명과 학교를 등록해 시작할 수 있습니다. NEIS 학교기본정보와 급식식단정보를 조회해 오늘 급식과 일간·주간·월간 급식표를 보여주며, 선택한 날짜의 메뉴·알레르기·전체 영양 정보를 상세에서 확인할 수 있습니다.

성장은 기존 1–7단계와 누적 XP를 보존하면서 12단계로 확장됩니다. 메뉴에는 음식 아이콘과 대표 영양소를 표시하고, 기록 저장 전 교육용 영양 안내를 확인합니다. 대표 영양소는 일반적인 교육 정보이며 실제 섭취량이나 의학적 결과를 진단하거나 보장하지 않습니다.

샘플 급식은 사용자가 체험 모드를 직접 선택한 경우에만 표시됩니다. 실제 학교 조회 실패, API 키 없음, 급식 없는 날에는 샘플로 자동 대체하지 않습니다.

알레르기 정보는 안전을 보장하지 않습니다. 관련 메뉴에서는 먹기 권유보다 학교 안내와 보호자 판단 확인을 우선합니다.

## 주요 기능

- NEIS 기반 학교 검색 및 실제 급식 조회
- 오늘 급식과 일간·주간·월간 선택 날짜 상세
- 메뉴별 음식 아이콘 및 대표 영양소 교육 안내
- 기존 사용자의 XP를 보존하는 12단계 캐릭터 성장
- 먹은 정도, 어려운 이유, 한 입 도전 기록
- 알레르기 주의 메뉴의 비회피 기록 차단
- 급식판 사진 기기 내부 저장
- 사용자가 선택한 기록만 부모 공유
- 회원가입 없음
- 광고, 인앱결제, 분석 SDK, 추적 SDK 없음

## 심사 메모

- 테스트 계정은 필요하지 않습니다.
- 체험 모드는 사용자가 직접 선택하며 실제 학교 데이터가 아닌 샘플임을 표시합니다.
- 조회 실패나 급식 없는 날에는 샘플 급식을 자동 표시하지 않습니다.
- 주간·월간에서 선택한 날짜와 정확히 일치하는 상세만 표시합니다.
- 대표 영양소 및 알레르기 안내는 교육용 참고 정보이며 학교 안내와 보호자 판단이 우선입니다.
- 사진은 기기 내부에만 저장하고 부모 모드나 서버에 업로드하지 않습니다.
- 부모 공유를 켠 식사 기록만 서버 공유 대상입니다.

## App Privacy 응답 초안

- Tracking: 아니요
- Third-party advertising: 아니요
- Analytics SDK: 없음
- Contact Info, Location, Contacts: 수집 안 함
- Other User Content: 부모 공유를 켠 식사 기록만 App Functionality 목적으로 서버 저장 가능
- Photos or Videos: 수집 안 함. 급식판 사진은 기기 내부에만 저장
- Health and Fitness: 알레르기 선택값과 식사 기록을 App Functionality 목적으로 보수적으로 신고
- User ID: 부모 연결용 초대 코드와 `childLinkId`를 App Functionality 목적으로 신고

최종 App Privacy 답변, 연령 등급, 법적 문구와 제출 여부는 앱 소유자가 App Store Connect에서 확인한다.
