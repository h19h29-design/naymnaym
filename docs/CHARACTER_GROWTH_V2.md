# 캐릭터 성장 V2

급식레벨업 1.2의 성장 기준은 `growth-policy.json` 한 곳에서 관리한다. 공개 1.1의 1~7단계 임계값은 그대로 유지하고 8~12단계만 추가한다.

| 단계 | 이름 | 누적 XP |
| ---: | --- | ---: |
| 1 | 냠냠 새싹 | 0 |
| 2 | 한 입 탐험가 | 80 |
| 3 | 냠냠 용사 | 180 |
| 4 | 편식 몬스터 사냥꾼 | 320 |
| 5 | 급식 히어로 | 500 |
| 6 | 영양 마스터 | 720 |
| 7 | 레전드 냠냠러 | 1,000 |
| 8 | 별빛 셰프 | 1,300 |
| 9 | 균형 수호자 | 1,650 |
| 10 | 숲의 영양 기사 | 2,050 |
| 11 | 황금 한입 챔피언 | 2,500 |
| 12 | 전설의 급식대장 | 3,000 |

## 데이터 보존 규칙

- 기존 XP 원장과 급식 기록을 다시 계산하거나 삭제하지 않는다.
- 기존 1~7단계 선택 스킨과 레거시 성장 권한을 새 단계 계산보다 낮추지 않는다.
- `highestUnlockedStageID`는 단조 증가하며, 총 XP가 늘어도 해금 단계가 내려가지 않는다.
- 새 상태가 없거나 손상된 경우 XP·레거시 권한으로 안전하게 복구한다.
- 체험 모드의 기록·XP·선택 단계는 메모리 세션에 격리해 실제 사용자 성장에 합산하지 않는다.

## 화면 계약

- 성장 화면은 현재 단계, 다음 임계값, 남은 XP, 12단계 로드맵, 선택 단계 이야기와 보상을 표시한다.
- 해금 단계는 컬러, 다음 단계는 미리보기, 잠긴 단계는 실루엣과 텍스트로 함께 구분한다.
- VoiceOver는 로딩·해금·잠금·그림 준비 상태를 실제 이미지 로더 상태에 맞춰 한 번만 읽는다.
- Reduce Motion에서는 반복 이동 대신 정적 상태를 사용한다.

## 원화 상태

검증된 기존 원화는 1~7단계까지다. 8~12단계는 다른 단계 그림을 새 원화처럼 재사용하지 않고 `그림 준비 중` 중립 상태로 표시한다. 출시 전에 필요한 최종 원화와 출처·체크섬은 [CHARACTER_ASSET_MANIFEST.md](CHARACTER_ASSET_MANIFEST.md)에서 관리한다.
