# Android 비공개 테스트 운영 계획

Google Play 새 개인 개발자 계정의 프로덕션 접근 신청을 위해 비공개 테스트에서 12명 이상 테스터가 14일 연속 opt-in 상태를 유지해야 합니다.

## 필요한 테스터 행동

1. 본인 Gmail 계정으로 테스트 링크 접속
2. 테스트 참여 수락
3. 앱 설치
4. 14일 동안 테스트 opt-out 하지 않기
5. 최소 2회 이상 앱 실행
6. 핵심 흐름 확인
   - 학교 검색/등록
   - 실제 급식 조회 또는 급식 없음/API 오류 안내 확인
   - 체험 모드 배지와 샘플 데이터 확인
   - 알레르기 메뉴 한 입 도전 잠금 확인
   - 먹은 정도/한 입 도전 기록
   - 보호자 초대 링크 공유
   - 개인정보/지원/데이터 삭제 화면 확인
7. 간단한 피드백 제출
