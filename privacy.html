개인정보 처리방침

시행일 및 최종 개정일: 2026-07-25

이 개인정보 처리방침은 냠냠레벨업 1.0 공개 배포 후보에 적용됩니다.

냠냠레벨업은 회원가입 없이 학교 급식 정보와 한 입 도전 기록을 사용할 수 있는 무료 급식 식습관 코칭 앱입니다.

토스 미니앱: 로컬 저장과 NEIS 조회

토스 안에서 사용하는 냠냠레벨업 미니앱은 별명, 선택 학교, 알레르기 선택값, 식사 기록, XP, 레벨과 급식 캐시를 토스 기기 저장소에 저장합니다. 미니앱 코드는 이 정보를 Supabase Database, Auth 사용자, Storage, Realtime에 사용자 기록으로 작성하지 않습니다.

토스 앱 또는 미니앱을 삭제하거나 토스 저장소를 지우거나 기기를 바꾸면 이 로컬 데이터가 사라질 수 있습니다. 미니앱 설정의 내 데이터 삭제에서 이 기기에 저장된 데이터를 직접 삭제할 수 있으며, 삭제한 데이터는 되돌릴 수 없습니다.

학교 검색어 또는 선택한 학교 코드와 날짜는 급식 조회 목적의 neis-proxy Supabase Edge Function으로 전달되고, 이어 NEIS API에 전달됩니다. 이 과정에서 요청의 Origin, IP 주소, User-Agent, 헤더 등 통상적인 네트워크·보안 메타데이터와 Supabase 플랫폼의 호출·로그 메타데이터가 처리될 수 있습니다. 함수의 애플리케이션 로그는 요청 ID, 작업 종류, 상태, 처리 시간만 남기도록 구현되어 요청 본문이나 키를 기록하지 않습니다.

Supabase 및 NEIS의 보관 기간, 처리 위치와 세부 처리 조건은 각 제공자의 정책 및 실제 선택한 Supabase 프로젝트 설정에 따릅니다. 출시 전(Task 11)에는 프로젝트 지역, 보관·로그 설정과 제공자 정책을 확인해 이 안내와 검수 자료를 갱신합니다.

iOS/Android 네이티브 앱: 기기 내부에 저장되는 정보

  • 별명, 선택 학교, 알레르기 선택값
  • 먹은 정도, 한 입 도전, 어려운 이유 기록
  • 캐릭터 레벨과 뱃지
  • 급식판 사진과 사진 메타데이터

iOS/Android 네이티브 앱: 공공데이터 조회

급식 조회를 위해 선택한 학교 코드와 날짜가 NEIS 학교기본정보 API와 급식식단정보 API 요청에 사용될 수 있습니다.

iOS/Android 네이티브 앱: 사진과 부모 연결

사진은 기기 내부에만 저장됩니다. 부모 공유를 켠 먹은 정도, 한 입 도전 기록, 알레르기 주의 정보만 부모 모드 표시와 급식 결과 알림을 위해 서버에 저장될 수 있습니다. 서버 부모 동기화에는 사진 원본을 업로드하지 않습니다. 친구 얼굴, 이름표, 반/번호가 포함된 사진 촬영을 권장하지 않습니다.

수집하지 않는 정보

  • 이름, 이메일, 전화번호
  • 정확한 위치정보와 연락처
  • 광고 식별자와 결제 정보
  • 공개 프로필, 자유 채팅, 공개 피드

광고와 추적

냠냠레벨업은 광고, 인앱결제, 제3자 광고 추적을 사용하지 않습니다.

알레르기와 영양 안내

알레르기 정보와 영양 안내는 교육용 참고 정보입니다. 앱은 알레르기 안전, 건강 상태, 영양 상태를 진단하거나 보장하지 않습니다. 학교 안내와 보호자 판단이 항상 우선입니다.

iOS/Android 네이티브 앱: 데이터 삭제

앱의 설정 > 데이터 관리에서 도전 기록, 프로필, 전체 데이터를 삭제할 수 있습니다. 토스 미니앱의 삭제 방법은 위의 내 데이터 삭제 안내를 따릅니다.

지원 및 데이터 안전

앱 사용 도움말과 문의 방법은 지원 안내에서, 데이터 설명은 데이터 안전 안내에서 확인할 수 있습니다.
